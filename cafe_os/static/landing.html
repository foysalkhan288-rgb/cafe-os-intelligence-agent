Features

Everything your cafe needs

A complete POS intelligence backend — from order intake to kitchen dispatch to inventory deduction. Strict schema, real-time updates, zero guesswork.

🧾

Order Orchestration

6-node LangGraph flow: customer lookup → parse → validate modifiers → calculate totals → dispatch KDS → deduct inventory. Atomic, stateful, resumable.

👨‍🍳

Kitchen Display (KDS)

Live WebSocket channel. Tickets push instantly. Staff acknowledge, start, and complete from any screen. Snapshot on connect, real-time updates.

📦

Inventory Deduction

Recipe BOM-based unit deduction on every order. Modifier units tracked separately. Low-stock alerts fire automatically when thresholds are crossed.

👤

CRM & Loyalty

Customer lookup by ID or phone. Reward points accrue on payment. 10% loyalty discount auto-applied at 100+ points. Preferences stored.

💰

Shift Reconciliation

Open/close shifts with expected vs actual cash tracking. Cash difference flagged for review. Payment totals bank onto the open shift automatically.

📈

Reports & Analytics

Daily sales, menu engineering matrix (stars/puzzles/plowhorses/dogs), waste analytics, branch comparison, and rolling-average sales forecasting.

🏷️

Modifier Engine

Extract modifier keywords from free-text special instructions. Map to ingredient deltas and price adjustments. Merged, deduplicated, validated.

🧠

LLM Order Parsing

Optional OpenRouter integration. Parse natural language orders into structured items. Activated via env var — works without it too.

🔒

API Key Auth

Env-gated authentication. Protect all endpoints with a single key. Disabled by default for local dev, enabled for production.

How it works

Three steps to a live cafe

Deploy in minutes. No complex setup, no vendor lock-in. Just push and go.

01

Deploy

Push to GitHub. Render auto-detects render.yaml and builds. Or run the bootstrap script on any VPS. Docker included.

git push origin main
02

Seed & Configure

Database seeds automatically on startup. Set OPENROUTER_API_KEY for LLM parsing. Set API_KEY for auth. That's it.

OPENROUTER_API_KEY=sk-... uvicorn cafe_os.main:app
03

Connect & Serve

Point your POS terminal at the API. Open the KDS screen for live tickets. Monitor inventory, shifts, and reports from the dashboard.

POST /api/v1/orders → KDS push → inventory deducted
API
